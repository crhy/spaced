THREE STEPS

Try it today. Install it when you are sure.

Spaced Linux runs straight from a USB stick. Nothing on your computer changes until you choose to install.

1

Download

One file, 1.6 GB, for any 64-bit PC.

Download the ISO

SHA-256 beb83d29d852cdafcb93d0d842a4f54a88c8b2ce1b8afaed9bab886ba233e40e

All files and release notes →

2

Put it on a USB stick

Any stick of 4 GB or more. Everything on the stick is erased.

On Windows use Rufus; on Windows, Mac or Linux use balenaEtcher. Choose the file you downloaded, choose the stick, press start.

3

Start your PC from the stick

Restart with the stick plugged in and pick it from the boot menu (often F12, F9 or Esc as the PC starts). Spaced Linux opens as a complete desktop you can use straight away.

When you like it, the Install icon on the desktop puts it on your disk. Help with each step →

COMING FROM WINDOWS?

Your PC still works. Keep using it.

Windows 10 is no longer supported, and many good computers are not allowed to run Windows 11. Spaced Linux runs on them, costs nothing, and can look like the desktop you already know: there are ten complete themes, including Windows XP and Windows 11 styles.

Your files stay yours, updates never restart your PC without asking, and there is no advertising in the desktop.

COMPIZ IS PART OF THE DESIGN

A desktop that moves with purpose.

Compiz is the primary window manager and compositor—not a novelty bolted on later. It provides fluid animation, workspace behavior, window organization, accessibility tools, keybindings, and the visual character of Spaced Linux.

HELP WHEN YOU NEED IT

Learn the desktop. Find the right app.

Spaced Welcome includes a concise Compiz quick start and task-based app suggestions. Each suggestion opens the exact app page in SpacedBazaar, ready to install.

Compiz quick start

Rotate the cube with Ctrl+Alt+left-drag and zoom with Shift+Super+mouse wheel. Use Shift+Print to capture an area.

Choose by task

Start with what you want to do—edit video, create graphics, record audio, play games, communicate, or write code.

Safe experimentation

After setup, check Timeshift for the “Fresh install” restore point and confirm snapshots work on your disk layout. Keep a separate backup of personal files.

BUILD IT YOURSELF

The complete distro lives in the repository.

Clone the project on a Debian- or Devuan-based host and build the same release image used by the project.

$ git clone https://github.com/crhy/spaced.git
$ cd spaced
$ make deps
$ make release
