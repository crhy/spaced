Spaced Linux removes needless friction for new users without hiding the operating system from people who want to understand and reshape it.

COMPIZ IS PART OF THE DESIGN

A desktop that moves with purpose.

Compiz is the primary window manager and compositor—not a novelty bolted on later. It provides fluid animation, workspace behavior, window organization, accessibility tools, keybindings, and the visual character of Spaced Linux.

When compositing is not appropriate, Marco remains available as a dependable fallback.

CONTROL WITHOUT CHAOS

Built to be understood.

Transparent foundation

Devuan and sysvinit keep services and startup behavior conventional and scriptable.

Native and sandboxed apps

APT powers the system while Flatpak delivers current desktop software.

Plain-text configuration

Package groups, overlays, theme mappings, scripts, and defaults live in version control.

Reproducible images

Build, validate, boot, and test the ISO through documented Make and QEMU workflows.

A customization base

Replace artwork, alter packages, create focused editions, or fork a new distribution.

Independent by design

A practical desktop vision rather than a large vendor's appliance ecosystem.

BUILD IT YOURSELF

The complete distro lives in the repository.

Clone the project on a Debian- or Devuan-based host and build the same release image used by the project.

$ git clone https://github.com/crhy/spaced.git
$ cd spaced
$ make deps
$ make release
