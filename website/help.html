SPACED LINUX 9.26

The current production release.

Spaced Linux 9.26 is the current production release. Download the ISO and matching checksum from the Spaced Linux 9.26 release page.

What is changing

Work focuses on complete system and application updates, display settings, graphics-driver recovery, desktop stability, and clearer help. Larger new applications and partitioning features are tracked separately.

What still needs testing

Physical NVIDIA and AMD GPUs, 4K displays, five-monitor arrangements, Wi-Fi cold starts, and suspend/resume need results from the affected hardware. A VM boot cannot confirm those fixes.

Choose when to test

Testing releases use a separate, signed update channel. Follow the instructions included with the testing release when it is published; switching to testing is an explicit choice. Use a spare disk or VM and keep a backup you have checked.

Download the ISO and its matching .sha256 file from the same release. In the download folder, run sha256sum -c spaced-linux-9.26-amd64.iso.sha256. Continue only when the result is OK.

DESKTOP QUICK START

Move, zoom, and capture.

Super is usually the key with the Windows logo. Custom shortcuts you have chosen may differ from these defaults.

Move between workspaces

Hold Ctrl+Alt and drag with the left mouse button to rotate the Compiz desktop cube.

Zoom the desktop

Hold Shift+Super and use the mouse wheel, or press Shift+Super+Up/Down.

Capture an area in 9.26

Press Shift+Print, then select an area for MATE Screenshot. Ctrl+Shift+left-drag is the Compiz capture alternative. Super+left-drag can conflict with the menu in older releases.

Open a terminal

Press Ctrl+Alt+T. The menu also has MATE Terminal and the system tools you use most often.

Change the look

Use Appearance Preferences to choose a Spaced theme. You can also choose your own wallpaper and icons.

Find an application

Welcome's Help & Apps tab suggests applications by task. Each suggestion opens its page in SpacedBazaar.

KEEP YOUR SYSTEM CURRENT

Applications and operating-system updates.

Install applications

Open SpacedBazaar to browse and install Flatpak applications. Welcome can install Bazaar and a selection of useful apps after setup.

Update Spaced Linux

Open SpacedUpdate, refresh the list, and apply the available updates. A complete update includes native system packages and Flatpak apps and runtimes. Let the operation finish and read any error before retrying.

Restart when needed

A new kernel or graphics driver needs a reboot to become active. Save your work first. If an update reports a failure, keep its log and include it with your support request.

Keep a separate backup of personal files before testing a release or changing drivers. Check that your Timeshift snapshots exist and can be restored; a system snapshot is not a backup of your documents.

GRAPHICS AND DISPLAYS

Start with the detected hardware.

In 9.26, open Spaced Video Drivers from the menu. Record your current GPU and display setup before a driver change, then keep the result and any error log.

NVIDIA

Let Spaced Video Drivers check which packaged driver supports the exact GPU. Names such as “GT 730” cover different hardware variants. If the tool reports no supported package, keep the working driver and share the diagnostic report before attempting a replacement.

AMD

9.26 includes the AMDGPU TearFree setting reported to fix RX 7600 scrolling artifacts in issue #177. It applies to AMDGPU devices. Use the driver tool to check updates, reboot when requested, and test scrolling, video, games, and resume on your display.

Multiple monitors and 4K

Use Monitor Preferences to set resolution and arrange displays to match your desk. Check one display at a time, then the complete layout. If a mode is absent or the arrangement will not save, include monitor connections and spaced-graphics-report output with the report.

If a driver change fails, keep the recovery result and log. Reboot after the tool confirms a completed change or successful recovery. An incomplete recovery needs attention before another driver change.

FILES AND EVERYDAY TASKS

Connect and get things done.

These starting points are also available in Welcome's local help. Device permissions, phone software, and network policies can affect the result.

Android and iPhone

Connect with a data-capable USB cable and unlock the phone. On Android, choose File transfer in the USB notification. On iPhone, approve Trust if prompted. Look for the device in Caja's sidebar; if it is missing, include the phone model and what appeared on both screens in your support request.

Windows network shares

In Caja, press Ctrl+L and enter smb://server/share, replacing the server and share names with yours. Supply the account allowed to access that share. Gigolo can keep connection bookmarks. Browsing a share does not enable sharing files from your Spaced computer.

Choose an application

Open Welcome's Help & Apps tab for task-based suggestions, or search SpacedBazaar. Typical starting points include Kdenlive for video editing, GIMP for images, Tenacity for audio editing, Ardour for recording, and LibreOffice for documents. Check each app's requirements before installing.

HELP US REPRODUCE IT

Useful details make fixes easier.

Include your Spaced version, whether you are using the live USB or an installed system, and the steps that trigger the problem. Tell us what you expected and what happened instead.

Displays and graphics

Include the GPU model, driver, monitor connections, resolution, and refresh rate. In 9.26, run spaced-graphics-report in a terminal to collect display and driver details. Review the output before sharing it.

Virtual machines

Include the VM application and version, BIOS or UEFI firmware, assigned RAM and CPUs, display adapter, and whether hardware acceleration is enabled.

Updates and applications

Include the failing application or package name and the error message. Describe whether it came from SpacedUpdate, SpacedBazaar, or a terminal command.
