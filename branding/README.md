# Spaced Linux Brand Assets

- `spaced-icon-fancy.png` — metallic website, launcher, and presentation icon.
- `spaced-mark-white.png` — flat white transparent mark for dark panels.
- `spaced-mark-black.png` — flat black transparent mark for light panels.
- `spaced-mark-light-gray.png` — flat light-gray transparent mark.
- `spaced-mark-dark-gray.png` — flat dark-gray transparent mark.

The monochrome marks share the same circle and stylized missing-S geometry and are suitable as starting assets for the Brisk Menu icon in the next release.
