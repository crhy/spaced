# Spaced Linux 11.26.1 release review

Date: 2026-11-13

This is candidate evidence, not a claim that issues are closed. Close a defect
only after its fix is merged to `main`; close a component issue only after that
component is also released. Do not publish the OS tag until the matching APT
archive is published and the installed-system upgrade gate passes.

Spaced Monitor 0.1.9 also distinguishes the process-stop controls: protected
session/system processes use the existing red X; ordinary processes use an
orange X. The backend remains authoritative and refuses protected-process
termination even if a UI caller is wrong.

The Welcome recommendation review keeps only four broadly useful defaults:
Spaced Bazaar, Brave, LibreOffice and VLC. Spaced RGB, Voxa, Audacious and the
games remain visible as opt-in choices. This keeps the initial Flatpak download
and background workload smaller without removing discovery.

## Release gates

- Install the verified `257.13-1+spaced11.26.1` elogind package set in the test
  VM. Its privileged Ceres build ran all 271 chroot-safe upstream tests; the
  sole excluded test requires a running elogind daemon and is covered below.
- In the installed VM, exercise menu reboot repeatedly and verify clean elogind
  logs, then test a real 11.26 to 11.26.1 APT upgrade and recovery from the
  historical #415 dependency state.
- Release Welcome 0.1.22 and Monitor 0.1.9 in their own repositories, then keep
  their exact archive hashes pinned in `config/external-artifacts.conf`.
- Run `make apt-repo-publish` for the matching `11.26.1-1` packages before or
  with the GitHub OS release. A tag without the APT packages recreates #209.
- Build and smoke-test the ISO, including installer reuse of a separate home
  partition, xkill cursor rendering, desktop hot-plug icons and the Monitor
  red/orange process controls.
