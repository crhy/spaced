# Spaced Linux 9.26 issue status

Audit date: 2026-09-08. This audit covers all 32 open issues in
[crhy/spaced](https://github.com/crhy/spaced/issues). It distinguishes a tested
source change from a fix confirmed on the affected machine. No issue was
closed as part of this audit. The agreed release scope is OS stability,
complete upgrades, and hardware reliability; larger new products remain
separate work.

The latest published OS image at this checkpoint is **8.26.9**. A local
9.26 build or passing source test does not establish that a downloadable
9.26 release has passed installation and hardware testing. See the
[testing record](9.26-TESTING.md) and [desktop audit](9.26-DESKTOP-AUDIT.md)
for commands and the evolving runtime evidence.

## Review of the Qwen handoff

Commit `e363dde` changed download buttons to a `v9.26` release asset before
that release existed. GitHub's release API confirmed `v9.26` was absent on
2026-09-08. The README and website now distinguish 9.26 preparation from the
published 8.26.9 download; the next publication must update labels and links
only after the ISO and its checksum are uploaded and verified.

The source and installed-system changes require their own execution tests;
a handoff note is not test evidence. Native package changes must receive a
new version once the existing package version is publicly indexed. Current
component revisions and the upgrade bootstrap review belong in the
[release testing record](9.26-TESTING.md).

## Tracker policy for the 9.26 release

Close a bug only when its acceptance check has evidence from the release
being published. A source fix awaiting a relevant VM or physical device
remains open with that limitation recorded. Keep deferred feature requests
open as roadmap work; closing them would imply work that has not been done.
