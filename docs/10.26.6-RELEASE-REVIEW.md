# Spaced Linux 10.26.6 release review

Reviewed on 23 October 2026, starting from commit `929e8a9`. This is a
pre-publication review, not a claim that every hardware configuration or
open issue is resolved. The release, APT repository and website have not
been published by this review.

## Changes made during this review

- Rebuilt Compiz as `2:0.8.18-9+spaced10.26.6` to protect decorator pixmaps
  between geometry lookup and GLX/Damage reference creation. A diagnostic
  stack traced the VirtualBox theme-switch failure to `decorGetTexture`.
  Final image validation follows the package rebuild.
- Backported the merged [Caja PR #1888](https://github.com/mate-desktop/caja/pull/1888)
  to `1.26.4-3+spaced10.26.6`. A filename chosen in the conflict dialog now
  survives a move between filesystems. The ISO and APT builders include all
  four matching binary packages and the APT repository includes the source.
  Source archives are pinned by SHA-256; the upstream patch and removal
  condition are documented in `patches/caja/`.
- Fixed the post-install restart after physically removing the ISO/USB
  medium. Importing code before removal was insufficient: Xorg and Python
  could still fault in pages from the missing medium. A small input/restart
  process now locks its mappings in RAM before showing the removal prompt.
  KVM reproduced the old failure and verified the fix by ejecting the ISO,
  pressing Enter and reaching the installed system's login screen.
- Added an opt-in live-VM theme check (`SPACED_VM_THEME_TESTS=1`) to both
  hypervisor smoke tests. It exercises all 13 presets, checks wallpaper,
  panel placement/size, dock visibility and desktop processes, and retains
  GTK, Caja and terminal screenshots. It refuses installed systems.
- Aligned website theme names with the chooser: Windows 7 Light and
  Windows 7 Dark.
- Prepared `docs/10.26.6-DISTROWATCH-EMAIL.md`, including the distinction
  between DistroWatch's last identifiable announcement and the latest
  version listing reported by the project's release tracker.

## Networking qualifications

The supplied peer at `192.168.88.186` is an OptiPlex running **Spaced Linux
10.26.5**, not Windows. Initial tests used installed 10.26.5 systems. Additional tests used the
10.26.6 VirtualBox candidate (Samba 4.25.1, GVfs 1.62.0) against that peer. The test used a uniquely named
temporary share and removed it afterwards. No user files or ongoing user
transfers were changed.

Both hosts passed Samba configuration/service checks. Guest transfers do
**not** verify a Windows client's Explorer discovery,
credential prompts, firewall policy or sleep/reconnect behavior. Authenticated SMB signing was separately tested against a disposable account
on the candidate, using a temporary VirtualBox port forward; the account,
share and port forward were removed. An actual Windows 11 client remains a
release validation item. WSD service startup was
checked; end-to-end discovery was not independently established.

An existing large SMB transfer was active during testing. Recorded transfer
times are therefore not a performance benchmark and do not close slow-copy
issue [#363](https://github.com/crhy/spaced/issues/363). An optional
`avahi-browse` command was unavailable after the successful transfer tests;
that command's failure is not a failed data transfer. An isolated test D-Bus
session also logged a keyring activation timeout; this is not evidence of a
normal desktop-session keyring regression.

## Upstream and outstanding issues

The review checked upstream and project reports, and chose a merged,
bounded Caja fix with a reproducible regression test. Existing Marco XRes,
Compiz decorator and Xorg AMD ABI patches remain in the release. Do not
interpret the Caja change as fixing all file-manager or networking reports.

These reports still need their own reproduction and evidence before closure:

- [#355](https://github.com/crhy/spaced/issues/355): copy cancellation hang.
- [#363](https://github.com/crhy/spaced/issues/363): slow SMB transfer.
- [#350](https://github.com/crhy/spaced/issues/350): stale application thumbnail.
- [#360](https://github.com/crhy/spaced/issues/360): OptiPlex hard crash.
- [#341](https://github.com/crhy/spaced/issues/341): update double-click behavior.
- [#362](https://github.com/crhy/spaced/issues/362): screenshot timestamps.
- [#361](https://github.com/crhy/spaced/issues/361): per-folder hidden-file persistence.
- [#334](https://github.com/crhy/spaced/issues/334): NVIDIA hardware coverage remains incomplete.
- [#351](https://github.com/crhy/spaced/issues/351): custom shortcut coverage remains incomplete.
- [#354](https://github.com/crhy/spaced/issues/354): Brisk context-menu feature request.

## Publication and remaining validation

- Merge the reviewed changes before closing any fixed issue. Separate Welcome
  and Bazaar changes require their own repositories and releases.
- Publish matching packages with `make apt-repo-publish` to `crhy/spaced-apt`
  together with the release. A GitHub tag without APT packages causes update
  loops. Never replace already published bytes under the same package version.
- Publish the tested ISO and its checksum, then verify the public download.
- Deploy the website and verify both bare and `www` domains. During this
  review they advertised different older releases; the local site says
  10.26.6 and has 13 themes. The website edits alone do not deploy the site.
- Confirm the current DistroWatch listing directly before sending the draft:
  direct retrieval was blocked, so the announcement baseline uses indexed
  evidence and the version-listing baseline is explicitly project-reported.
- Test an actual Windows client and affected physical NVIDIA/AMD hardware.
  VM success does not establish suspend/resume, audio device switching,
  Wi-Fi roaming, GPU acceleration or the reported physical-machine crash.
