Rendered with Pango and Cairo at 10 pt with the shipped text scaling of 1.2, which is what a stock desktop shows. Width is the pixel width of a 60-character sentence, so a smaller number fits more text on a line. x-height is the pixel height of a lowercase x, and line height is the pixel height of one line.
