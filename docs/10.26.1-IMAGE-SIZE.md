# 10.26.1 image size audit

Measured against the read-only filesystem from the published 10.26 ISO in the
CPU-rendered KVM guest. The build chroot contains restored build caches and is
not a reliable measure of what ships in the ISO.

## Additional cleanup

The final chroot hook removes package changelog files and changelog symlinks.
It retains copyright/license files, NEWS upgrade notes, README files, examples,
manuals, desktop help and all translations. APT's two generated binary indexes
are also excluded at squashfs creation, because live-build can recreate them
after chroot hooks run. No packages are removed.

Testing a copy of the actual ISO's documentation and APT binary indexes removed
1,904 regular files totaling **36,996,898 bytes**. All 3,422 remaining regular
files in that sample matched their original SHA-256 hashes. Behavioral tests
also cover retained firmware, modules and service caches, symlink boundaries,
repeat execution and rejection of an unpopulated target.

Recompressing the sample with `mksquashfs -comp xz -processors 2` produced:

| Sample | Bytes |
|---|---:|
| Before cleanup | 32,153,600 |
| After cleanup | 9,900,032 |
| Saving | 22,253,568 |

This is an isolated payload comparison, not a measured whole-ISO reduction.
The final 10.26.1 ISO is **1,683,140,608 bytes**, compared with
**1,745,436,672 bytes** for 10.26: **62,296,064 bytes smaller (3.57%)**.
These are complete release images, including rolling-base changes (kernel
7.2.8 to 7.2.9), rather than a controlled compression-only comparison.
Fresh CPU-rendered KVM live boots passed in 43 seconds (BIOS) and 53 seconds
(UEFI). The Safe Graphics entry also reached the MATE/Compiz desktop with
its nomodeset and NVIDIA/Nouveau fallback flags active.
Artifacts are under the ignored `build/slimming-audit/` directory. This cleanup
ships in the new ISO; it does not delete documentation from existing systems
through an APT upgrade. Future package upgrades may reinstall changelogs.

## Other candidates reviewed

- Downloaded packages and repository indexes: already omitted from the finished
  ISO by live-build. Preserve host caches to make rebuilds faster.
- Firmware, Mesa, kernel headers and compiler tools: retain hardware support,
  CPU rendering and the ability to build DKMS drivers, including NVIDIA.
- MathJax: roughly 43 MB in the live filesystem, but a dependency of Atril's
  document library. Removing it would impair document rendering.
- Icons, translations and help: serve the supported desktop themes, languages
  and offline help. No removals in this patch.
- Initramfs: large, but needed for live boot and installation. No module or
  firmware pruning, and no host-specific `MODULES=dep` setting.

The earlier wallpaper optimization is separate: 54,831,140 to 13,056,818
uncompressed bytes, with compatibility paths retained.
