# Spaced Linux 9.26.1 issue status

Audit date: 2026-09-10. This covers all 21 issues open in
[crhy/spaced](https://github.com/crhy/spaced/issues) at the time 9.26.1 was
prepared. It follows the tracker policy established for 9.26: a tested source
change is not the same thing as a fix confirmed on the affected machine, and no
issue is closed here.

**9.26.1 is published.** The ISO was built from this branch, booted to the
live desktop headlessly in both firmware modes (BIOS in 36 seconds, UEFI in
48), and released with its checksum. The 9.26.1 packages are in the signed
APT repository, so an installed 9.26 system offers `spaced-meta 9.26.1-1` as
its candidate without reinstalling.

## Session efficiency work

These are not tracker issues; they came out of reading every session helper
that runs on a Spaced desktop.

- `spaced-audio-restore` saved state on every PulseAudio sink event, spawning
  three `pactl` processes each time. Dragging the volume slider therefore
  produced a burst of process spawns. Events are now coalesced into one save.
- `spaced-enable-flatpak-remotes` retried every two seconds for three minutes.
  On a machine that is simply offline that is ninety rounds of several Flatpak
  processes for no possible gain. It now backs off to a thirty-second interval.
- `spaced-theme-monitor` started a Python interpreter per theme change to read
  a table that never changes during a session. It is read once at startup.
