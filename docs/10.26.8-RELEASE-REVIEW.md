# 10.26.8 release review

Publication status: **accepted with limited scope**. The release contains the
verified fixes for #371, #379 and #381 plus removal of the Brave policy crash
trigger. The intermittent greeter report (#374) and the unreproduced Brave
minimized-window/data-loss report (#380) remain open and are not claimed fixed.

## Release issue evidence

| Issue | Change and observed result | Release disposition |
| --- | --- | --- |
| [#371](https://github.com/crhy/spaced/issues/371) | Rebuilt Compiz main plugins intercept XI2 smooth scrolling when the configured zoom chord is held. A Qt wheel-event probe reproduces the original bug. Patched package: zero events while zooming; eight events after release or an extra modifier. Binding changes, plugin unload/reload and repeated runs release and restore the grab correctly. | Included in the final ISO; close after merge and release. |
| [#379](https://github.com/crhy/spaced/issues/379) | Caja's hidden-files preference survives window closure and process restart, both enabled and disabled. Brisk Edit Menus opens installed Alacarte. A custom panel icon survives panel restart; Restore Default Menu Icon restores the schema default through the actual context menu. | Included in the final ISO; close after merge and release. |
| [#381](https://github.com/crhy/spaced/issues/381) | Welcome 0.1.21 removes the unsupported Flatpak remote-add option. Component PR15 is merged and v0.1.21 released. Released Debian artifact independently checksum-verified. A fresh-user VM probe installed Brutal Chess successfully after fixing the missing machine-ID alias for AccountsService. | Welcome 0.1.21 and the machine-ID alias are included in the final ISO; close after merge and release. |
| [#380](https://github.com/crhy/spaced/issues/380) | Removed managed DefaultBrowserSettingEnabled=false, which triggers a documented upstream settings assertion. Brave 1.98.63 preserved a test draft and the same process across minimize/restore. | Original draft-loss failure was not reproduced. This Flatpak build has no working Make Default button, so that crash path was not verified. Keep open. |
| [#374](https://github.com/crhy/spaced/issues/374) | Reporter identifies the OptiPlex, one cold-boot occurrence, no recurrence. No failure logs establish whether the greeter or graphics driver failed. | Keep open. On recurrence collect LightDM/greeter logs, Xorg log, lspci -nnk and GPU-related dmesg before restarting the display manager. VM success cannot validate this hardware failure. |

- Native source builds passed for Caja, Brisk and Compiz main plugins.

  `49957408cc560de2195e0ef0fa304bc3e5442187b47c4fd988760e2e40f0d73d`.
