# Spaced Linux 11.26.1 release images

Screenshots of the released live ISO, taken headless in QEMU (KVM, BIOS,
1920x1080) with scripts/vm/qemu/release-shots.sh and QMP screendump.

- ISO: spaced-linux-11.26.1-amd64.iso
- ISO sha256: 937030fcb2103d5115ddda6d2e9ade497d239b1ff250352ee01bb34a734b1d6f
- VM: KVM, BIOS, 4096 MiB RAM, 4 CPUs, virtio-gpu at 1920x1080, headless
- Every PNG has a same-name .webp (quality 90) for the release page.
- Window list and OCR text of every frame: build/vm-tests/r01/spaced-linux-11.26.1-amd64/
  (shot-<name>.windows.txt proves which window was open,
   shot-<name>.ocr.txt is the text read back out of the pixels).

## Card crops (used in the release page's 2-column table)

`card-<name>.png / .webp` is the same frame as `shot-<name>`, cropped to its app
window plus 48 px of wallpaper margin on every side. Nothing was redrawn,
upscaled or retouched: the card is a rectangle cut out of the original
1920x1080 frame, at full resolution. The crop box starts from the window in
`shot-<name>.windows.txt` (wmctrl -lpG reports exactly twice the real position,
so x and y are halved) and is grown over the title bar and borders found by
diffing the frame against `shot-desktop-dark.png`, which is the same desktop
with the same wallpaper, so unchanged pixels differ by exactly 0. The only
pixels that differ outside a window are the panel clock (rows 1050-1079), which
stays out of every card.

| file | window | card size | window share of the card |
|---|---|---|---|
| card-spaced-monitor.png / .webp | Spaced Monitor (1400x900 client) | 1504x1021 | 86 % |
| card-spaced-welcome.png / .webp | Spaced Welcome (984x720 client) | 1090x853 | 81 % |
| card-caja-set-wallpaper.png / .webp | Caja "Pictures" with its right-click menu (960x660 client) | 1066x794 | 80 % |
| card-live-rescue-gparted.png / .webp | GParted on /dev/sr0 (920x640 client) | 1021x774 | 79 % |
| card-spaced-update-os-release.png / .webp | Spaced Update, OS Release tab (900x733 client, GTK header bar, no window manager title bar) | 996x829 | 80 % |

- The monitor card has 40 px of margin on top instead of 48 because its title
  bar sits 40 px from the top edge of the frame; every other side has 48 px.
- The GParted card does not contain the `Live session passwords.txt` desktop
  note: that note sits at x=46-125 of the frame, while the GParted window sits
  at x=889-1814, so it is cropped out. Use `shot-live-rescue-gparted` for that.
- Generated by `.strata/out/r03-cards.py` (crop only, no drawing); re-run it to
  reproduce these files from the six `shot-*` frames.
