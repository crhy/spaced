# 10.26.2 issue verification

Scope: the point-release items in `docs/10.26.2-ISSUE-PLAN.md`. Roadmap
projects remain open. Automated tests use CPU rendering and KVM without GPU
passthrough.

## Evidence collected

`make release-preflight` passes: source and package checks and 176 unit tests.
The 10.26.2 ISO (SHA-256 `eb963fe2d4b75c5e6eedbdfe92cd687df44b8b2c85bec5977bbf5cc3d0590d45`)
booted to the live MATE/Compiz desktop in KVM under BIOS (37 s) and UEFI with
no dpkg audit findings; a screenshot at 105 s shows the wallpaper, desktop
icons and panel in Roboto.

rhY tested the upgrade path by hand: the installed 10.26.1 KVM disk was pointed
at locally built, signed `10.26.2-1` packages and upgraded through Spaced
Update. The two faults found there (Spaced Welcome saying "Open" for apps that
were not installed, and "Install" for SpacedBazaar when it was) were fixed in
Spaced Welcome 0.1.19, which was released after that test and is checked by its
own 58 tests and screenshots on a virtual screen, not by a second hand test.
The package payload test (149 runtime dependency checks) and the APT trust test
pass on the repository.

## Not verified

- No fresh Calamares installation of the 10.26.2 ISO was run.
- VirtualBox and Safe Graphics boots were not repeated for this release.
- Physical NVIDIA, AMD and multi-monitor hardware.
