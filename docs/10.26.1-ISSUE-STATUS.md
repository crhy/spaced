# 10.26.1 issue verification

Scope: actionable bugs and release polish. Roadmap projects remain open.
Tests use CPU rendering and KVM without GPU passthrough.

## Evidence collected

`make check` passes: source/package checks, 168 unit tests, and two GTK tests.
The initial VM is the published 10.26 live ISO upgraded with development
10.26.1 packages. Fresh 10.26.1 KVM BIOS and UEFI live boots also passed (43s and 53s).
The separate Safe Graphics boot reached MATE/Compiz using CPU rendering,
with nomodeset and NVIDIA/Nouveau fallback flags verified in /proc/cmdline.
VirtualBox BIOS and EFI (VBoxSVGA, 3D disabled) also passed desktop and
Calamares launch checks, reaching readiness after 40s and 35s.
A fresh BIOS Calamares installation completed in about 2m48s, displayed the
remove-media prompt, and booted from disk. Password login and a second login
after reboot passed, including encrypted keyring unlocking, 50% unmuted audio,
Num Lock, hidden-file defaults, Samba and the Flatpak theme override. Temporary
SSH and secret-tool probes were added only to the disposable installed VM.
