## Implemented Linux issue candidates

All issues in this section remain open because the fixes are not on Linux
`main` and the OS is not released.

### #415: failed Perl/package update and recurrence prevention

- `spaced-update-helper` now retains failed APT simulation output, refuses to
  continue after a failed simulation, and checks both dependency and pending
  dpkg state before and after the transaction.
- `/etc/apt/apt.conf.d/60spaced-transaction-guard` adds an independent
  pre-unpack guard for command-line APT transactions. A UI mistake therefore
  cannot be the only protection against an unhealthy package state.
- APT archive construction and publication require nonempty historical
  installed-package fixtures. The exact 11.26 fixture and retained 7.26
  fixture both exercise the candidate archive.
- Tests cover visible solver diagnostics, abort behavior, dependency/dpkg
  health checks, pre-install guard behavior, empty-fixture rejection, candidate
  exercise, and rejection of core Spaced package removal.
- The reusable rule is in `docs/FIXES.md`: do not unpack after failed solving,
  do not hide solver output, and do not publish without historical resolution.

### #409: elogind reboot-helper crash

- Two exact upstream fixes are carried under `patches/elogind/`: the
  poweroff/reboot segfault fix and XML entity-resolution fix.
- Source hashes are pinned and the build is integrated into the isolated Ceres
  package build and staging path.
- Candidate version: `257.13-1+spaced11.26.1` for `elogind`, `libelogind0`,
  `libelogind-compat`, and `libpam-elogind`.
- The privileged Ceres build ran all 271 chroot-safe upstream tests: 268
  passed, three skipped, zero failed. The one daemon-dependent path must still
  be covered by repeated reboot testing in an installed VM.

### #413: reused home missing from installed `fstab`

- A Calamares post-`fstab` module checks the final partition plan against the
  installed `fstab`.
- It repairs only the one identifiable missing `/home` entry. It stops safely
  rather than touching the old home when reuse disappeared from the final
  plan, multiple candidates are present, or the partition cannot be identified.
- Eight regression scenarios cover the repair and refusal cases.
- The reporter's original upstream trigger is not claimed proven because the
  original Calamares log and exact disk layout are unavailable. A final-ISO
  separate-home reuse installation remains mandatory.

### #406, #407 and #412: desktop icons outside the visible work area

- The Caja desktop repair is event driven for desktop and metadata changes,
  handles hot-plugged or moved items, and respects the current monitor/panel
  work area.
- Boundary regressions cover the external behavior.
- Live multi-display and panel-layout checks remain part of final ISO smoke.

### #408: missing Brave/Caja portal locations

- A login repair validates the Flatpak portal permission database and repairs
  damaged state without a broad permission reset or removal of unrelated
  locations.
- Dedicated tests cover healthy, corrupt, and repair behavior.

### #414: xkill cursor

- The user-supplied `/home/rhy/Pictures/xkillcursor.svg` was copied into the
  source tree as `branding/cursors/xkillcursor.svg` and built as the Xcursor
  `pirate` action.
- It is intentionally used only by `xkill`; ordinary window close controls and

- Cursor generation and scope are regression tested. Rendering still needs to

### #303: wallpaper placement

- Caja gains **Set as Wallpaper...** through a Caja Python extension and a
  separate dialog/helper.
- The implementation copies the image into private user storage, recommends a
  crop-or-fit mode from the image/display ratios, and asks the user for the
  final placement.
- Tests cover safe naming/copy behavior and ratio recommendations.

### #397: Easy Effects with PulseAudio

- Spaced Bazaar receives a host blocklist entry for Easy Effects while the OS
  remains on PulseAudio. This avoids offering an application whose required
  PipeWire processing path is unsupported without expanding a patch release
  into an audio-stack migration.

## Efficiency and stability work in the candidate

- Desktop-icon correction reacts to relevant changes rather than polling.
- The updater performs cheap health checks before destructive work and fails
  closed on uncertain dependency state.
- The Calamares guard is a narrow invariant check and does not rewrite a valid
  `fstab`.
- Damaged portal state is repaired selectively instead of resetting every
  application permission.
- Welcome's default application set is smaller, reducing initial Flatpak
  downloads and background workload.
- Release inputs are exact-version and SHA-256 pinned, preventing silent
  component drift.
- The distribution remains sysvinit/elogind based; no systemd migration or
  unrelated feature expansion was introduced.
