# 10.26.3 issue verification

Scope: #295, #296 (text), #297 and #298. Released at rhY's request before the
full on-network matrix in `docs/10.26.3-TEST-PLAN.md` ran; the rows not run
are listed below.

## Evidence collected

`make release-preflight` passes: source and package checks and 188 unit
tests. `make apt-repo` passes the package payload test (149 runtime
dependency checks) and the APT authenticity tests.
