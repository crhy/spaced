# Spaced Linux 9.26.3 issue status

Audit date: 2026-09-14. This covers the 9.26.3 patch release, which rolls the
post-9.26.2 source fixes into a new OS version. A source change is not treated
as hardware confirmation, and roadmap requests are not mislabeled as
point-release defects.

**9.26.3 was published on 2026-09-15.** The native package
set is `spaced-meta`, `spaced-mate-default-settings` and `spaced-themes` at
revision `9.26.3-1` plus `spaced-wallpapers` at `2026.09-1`. The Welcome pin is
unchanged at 0.1.15, so no new Welcome release is required. Hardware-specific
issues remain open until they are confirmed on the affected physical systems.

## Fixed in source

| Issue | 9.26.3 change | Release acceptance |
| --- | --- | --- |
| [#217](https://github.com/crhy/spaced/issues/217) Should Spaced Update do autoremove and autoclean? | The updates page offers an optional, confirmed "Clean Up" action that plans `autoremove`/`autoclean` through the privileged helper, shows what would be removed, and only proceeds on confirmation. Protected desktop, init, and running-kernel packages (or an unusually large removal set) disable removal for safety. Updates themselves never clean up automatically. | Open Spaced Update, run Clean Up, confirm the plan matches expectations and protected packages are never offered for removal. |
| [#219](https://github.com/crhy/spaced/issues/219) Screensaver | "Activate screen saver when computer is idle" no longer unticks itself when display sleep is "Never". Only a real display-sleep transition changes screensaver idle activation now; login, unlock and the 30-second DPMS reconcile only reapply xset. | Set display sleep to Never with the screensaver box ticked, wait out the reconcile interval, and confirm the box stays ticked and the screen stays on. |
| [#190](https://github.com/crhy/spaced/issues/190) Network Servers icon is purple, not gray | Both Spaced-Menu-On-Dark and Spaced-Menu-On-Light now ship the gray artwork as `scalable/places/network-workgroup.svg` (the name Caja actually requests for the desktop item) plus `network-server.svg` for individual hosts. The 9.26.2 hicolor fallback never took effect because every selectable theme inherits a Spaced-Menu-On-* theme before Papirus and hicolor. | Check the Network Servers desktop icon under every shipped light and dark icon palette. |
| [#218](https://github.com/crhy/spaced/issues/218) VirtualBox installer will not launch | When Compiz cannot start (no working 3D graphics), the session now shows a keyboard-usable explanation with the VirtualBox VBoxSVGA recovery steps and Log Out / Open Terminal actions, instead of a painted but unresponsive desktop. The VirtualBox smoke test now exercises both graphics profiles (`make vbox-smoke` for VBoxSVGA, `make vbox-smoke-default` for VirtualBox defaults), records the chosen controller, reports a Compiz-cannot-start outcome distinctly as `NO WINDOW MANAGER` (exit 3), and launches the live installer over SSH in both profiles. | Reproduce the reporter's VirtualBox configuration and confirm whether the installer now launches; on controllers without working 3D, confirm the recovery dialog appears and is operable. |
| [#80](https://github.com/crhy/spaced/issues/80) Windows Networking Installer | Network Servers discovery now works: the image ships `avahi-daemon` and `libnss-mdns` for mDNS/DNS-SD browsing of Macs, Linux servers, NAS devices and printers (including `host.local` names), `wsdd` for Windows 10/11 PCs, and the `smbclient` diagnostic tool. The only new always-on listener is mDNS on UDP 5353. | Browse Network Servers on a network with Mac, Linux, NAS and Windows 10/11 hosts and confirm each appears. The full graphical Samba setup wizard remains a roadmap item. |
| Artwork package split | `spaced-mate-default-settings` is split into three packages: `spaced-wallpapers` (wallpapers, independently versioned at `2026.09-1`), `spaced-themes` (themes, icons, and GRUB artwork, pinned to the settings version), and a leaner `spaced-mate-default-settings` that depends on both. Desktop fixes no longer re-ship the full artwork payload on every APT update. | Upgrade an installed 9.26.2 system and confirm the split packages install, the Breaks/Replaces takeover succeeds, and themes, icons and wallpapers are unchanged. |
| APT repository pruning | `make apt-repo` now runs `scripts/prune-apt-repo.sh --apply` first (newest 2 revisions per package plus exact `spaced-meta` pins, `SPACED_APT_KEEP` overridable), keeping the 1 GB GitHub Pages site from growing forever. | Publish the 9.26.3 package set and confirm superseded revisions are pruned while pinned `spaced-meta` revisions remain installable. |
| [#158](https://github.com/crhy/spaced/issues/158) Super+left-drag opens the Brisk menu | The Compiz screenshot binding is Ctrl+Shift+left-drag, migrated for existing profiles and documented in help; `check.sh` now rejects any plain `<Super>Button1` binding. The tutorial video part stays on the roadmap. | Drag with Ctrl+Shift+left mouse button and confirm a screenshot is taken without the menu opening. |

The fixes above reach installed systems through Spaced Update; the 9.26.3 ISO
carries them for fresh installations.

## Release evidence

1. The official ISO workflow run
   [34914685154](https://github.com/crhy/spaced/actions/runs/34914685154)
   passed `make check`, the clean build, and the BIOS, UEFI and 4K KVM
   live-desktop smoke tests at source commit `b917cf6`, which is tagged
   `v9.26.3`.
2. The published `spaced-linux-9.26.3-amd64.iso` is 1,797,443,584 bytes with
   SHA256 `b1d59ec0ae9adb815a9bacff3185785ad8a802631b2499c49cd3ff62b5b86865`
   (also recorded by GitHub for the release asset).
3. VirtualBox 7.2.16 smoke tests on that ISO passed on BIOS and EFI with both
   profiles: `make vbox-smoke` (VBoxSVGA) and `make vbox-smoke-default`
   (VirtualBox chose VBoxVGA). Each reached the MATE/Compiz desktop in 25–40
   seconds and opened the Calamares window within 5 seconds. The live desktop
   shows the gray Network Servers icon (#190).
4. APT publication: `crhy/spaced-apt` commit `394cae3` publishes
   `spaced-meta`, `spaced-mate-default-settings` and `spaced-themes` at
   `9.26.3-1` and `spaced-wallpapers` at `2026.09-1`. The first pruning run
   removed 16 superseded packages (407 MB); the published package files went
   from 508 MB to 233 MB. The payload (139 dependency checks) and APT trust
   tests passed, and the published packages are byte-identical to the ones
   upgrade-tested.
5. `scripts/test-upgrade-packages.sh` resolved a signed full upgrade from a
   clean state and from the dpkg status of a real installed 9.26.2-2 system:
   no package removals, no `systemd` or `systemd-sysv`, and the split artwork
   packages take over from `spaced-mate-default-settings`. These are solver
   tests, not boot tests.

## Local release validation

- `bash scripts/check.sh` passes: release identity (VERSION, ISO config, os-release, lsb-release, Calamares branding, GRUB entries, live-build ISO name) agrees on 9.26.3, and the native package version matches the OS release.
- `python3 -m unittest discover -s tests` passes.
- `bash scripts/tests/test-release-identity.sh` passes: the real postinst and file triggers upgrade the release markers under dpkg and survive a later upstream unpack.
