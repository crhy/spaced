# 10.26.4 issue verification

Scope: #301, #313, #315, #316 and #318.

## Evidence collected

`make release-preflight` passes the source and package checks, 189 unit tests
and two GTK integration tests. The release identity test passes a real upgrade
to the `10.26.4-1` packages and verifies the resulting release files and dpkg
trigger behavior. The duplicate-source shell test covers exact duplicates,
comments, disabled entries and customized repository definitions.

The 10.26.4 ISO (SHA-256
`5f5f34ba85c2d6d19f6d52bc38586f5f599990bff207a46b899c835e3f582aa9`,
1,762,953,216 bytes) booted to the live MATE/Compiz desktop in KVM under BIOS
(131 s) and UEFI (126 s). Both boots reported Spaced Linux 10.26.4, the
10.26.4-1 settings and meta packages, no runtime errors and no dpkg audit
findings. The captured 1280x800 desktop frames were nonblank.

| Issue | Change and current evidence |
|---|---|
| #301 | New profiles set `org.mate.screenshot include-border` to false, so window captures omit Marco's transparent resize area. The schema default and package payload checks pass. |
| #313 | Caja inline rename entries use the theme text color for their insertion caret in ordinary windows. The GTK CSS is present in every generated theme and validated by the package checks. |
| #315 | `yelp` and `mate-user-guide` are required by `spaced-meta`; both were installed while building the ISO, and both BIOS and UEFI boots completed with the resulting package set. |
| #316 | The settings package removes `spaced-apt.sources` only when the active deb822 source exactly duplicates the signed, package-owned `spaced-apt.list`. Disabled, extended or customized sources are retained. The dedicated migration test passes. |
| #318 | Desktop rename entries now have an explicit dark surface, white text and white insertion caret. The GTK CSS is present in every generated theme and validated by the package checks. |

The visual CSS and screenshot behavior still need confirmation on physical
hardware after release; the automated evidence verifies the shipped defaults,
generated themes and complete live desktop, not pixel-level interaction with
those controls.
