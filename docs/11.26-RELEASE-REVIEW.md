# 11.26 release review

Publication status: **approved for publication** on 2026-11-06 at `0928d7e`,
on the owner's instruction that Claude's review of the final-image evidence
replaces Astra's sign-off. This is an evidence record, not a claim that the
OS is free of defects.

## Final image

- Clean build at `0928d7e`: `spaced-linux-11.26-amd64.iso`, 1,634,871,296
  bytes, SHA-256
  `d3a9b7a536cd4075c48771f9bb00d9352ba70bfe6e3eb8e55a426cc6a0c9a05a`.
- `make HOST_RUN= check` passed 289 unit tests and three GTK checks, including
  the panel-polarity, Linux Light volume-artwork and mixed-theme sidebar-disk
  regressions that were red before this revision.
- QEMU BIOS and UEFI at 3840x2160 reached the Compiz desktop with SysVinit,
  an empty `dpkg --audit`, `VERSION_ID="11.26"`, Spaced Monitor 0.1.8 and
  `pulseaudio-module-bluetooth` installed. All 13 theme switches passed on the
  BIOS image; the WinXP, GeoWorks and Linux Light panels were inspected
  visually for tray-icon contrast.
- Calamares installation, Welcome/Bazaar and Brave minimize checks were not
  repeated on this image; the changes since the diagnostic image are theme
  assets, a theme registry flag, one added audio package and the Monitor pin.

## Decisions

- Audio: PulseAudio is retained and `pulseaudio-module-bluetooth` added. Easy
  Effects needs PipeWire and cannot process audio on 11.26; #397 stays open.
- #380 stays open, labelled as needing reproduction.
- #399: the GUI path (GDebi) is the workaround; APT's harmless `_apt` warning
  still prints for manual installs from a private directory, so #399 stays
  open.

## Open release gates

- Build and test the final source revision. The first ISO build at
  `9c3c820` failed during compression; attempting to resume exposed missing
  live-build nested staging state. A clean build at `3d81a13` completed
  with compression limited to two workers and 1 GiB of cache. Its diagnostic
  ISO SHA-256 is `e0b1bdbe7c6db42903c872a1836ad29d43083be8ecce8c3228c4ae930264dd96`.
  Subsequent theme fixes require rebuilding this image. Host memory
  pressure was observed, but the original failure's cause is unconfirmed.
- Validate BIOS, UEFI and high-resolution live desktops, all 13 themes,
  package health and init identity; visually inspect the captured output.
  The diagnostic image passed BIOS and UEFI/3840x2160 smoke tests, with SysVinit,
  Compiz and clean package status. All 13 theme switches passed their automated
  checks. Astra's visual inspection nevertheless found light fallback icons,
  disabled-label contrast and slider-border defects; source fixes and new GTK
  regression checks pass, but final-image screenshots still need repeating.
  Applying the exact icon/CSS changes to a disposable live VM also passed all
  13 theme switches and the desktop health probe. The updated source gate
  passes 282 unit tests and three GTK checks. This does not replace rebuilding
  and testing the final image.
  A subsequent visual recheck exposed stale per-user theme exports hiding
  updated system CSS. The switcher's stamp now includes nested metadata and
  ctime; changed exports use checksum comparison, and failed copies/grants
  retry. Four isolated regressions cover same-size/preserved-mtime updates,
  unchanged fast paths and both failure modes. A fresh desktop session with
  these exact changes passed all 13 theme switches; visual review is pending.
- Complete a Calamares disk installation and boot the installed system;
  verify accounts, permissions, networking, audio, launcher integration,
  Welcome, Bazaar and Monitor rather than only opening the installer.
  Calamares successfully installed the diagnostic image onto a disposable 25 GB
  virtual disk. Reboot reached a complete greeter before any input, with the
  expected Spaced avatar. Login succeeded for the new UID 1000 account and
  Welcome appeared automatically. This is virtual-hardware evidence, not a
  physical GPU, suspend/resume or Bluetooth validation.
  Astra also passed 20 real Brisk search/Caja launch/context-menu cycles with
  stable desktop process IDs, and created, launched, renamed and removed a
  temporary Mozo menu entry with live Brisk refresh.
  Welcome successfully installed Bazaar 0.1.15 from the signed first-party
  origin and Brave 1.99.55 from Flathub. Bazaar's catalog opened populated.
- Recheck #397 through Bazaar installation and application launch.
  EasyEffects requires PipeWire, while the current image selects PulseAudio;
  corrected install-state reporting alone does not establish launch support.
  The audio-stack decision is awaiting the user's response. Include and test
  the appropriate Bluetooth-audio backend whichever stack is retained.
- Reproduce and resolve #380's minimized Brave window/draft-loss report, or
  obtain explicit acceptance of a documented limitation. Non-reproduction
  is not grounds for closing the issue.
  On the installed diagnostic image, Brave passed 20 Alt+F9 minimize/restore
  cycles with a fresh temporary profile, including a 60-second minimized
  interval with Caja in use. Unsaved textarea/rich-text drafts, document
  identity, heartbeat and process/window identity survived. This does not
  cover the reported user's profile, titlebar/taskbar paths or physical GPU.
- Resolve and test upgrades from previous package states against a signed
  candidate repository; record any removals. Solver success is not a boot test.
- Obtain Astra's final review of built-system evidence, merge the distribution
  PR, publish immutable signed APT packages, then publish the OS tag and ISO.
  Close only issues whose fixes have merged and shipped.
