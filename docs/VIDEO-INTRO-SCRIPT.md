# Spaced Linux introduction video

Target length: about 75 seconds.

## Script and shot list

**[0:00 — Desktop reveal; slowly move across the default desktop]**

“Meet Spaced Linux: a polished, familiar desktop built on Devuan, MATE, Compiz, and sysvinit.”

**[0:08 — Open the menu, file manager, and a few settings windows]**

“It is designed to feel comfortable from the first boot, while keeping the system modular, transparent, and completely free of systemd.”

**[0:20 — Show the theme selector; quickly preview several layouts]**

“Choose from ten complete desktop themes inspired by classic and modern systems—from Windows 3.11 and XP to macOS, Android, Mint, and Spaced Linux’s own dark and light designs.”

**[0:36 — Show Compiz workspaces and one restrained desktop effect]**

“Compiz brings smooth workspaces, accessibility, and useful desktop effects without turning the experience into a distraction.”

**[0:47 — Open Welcome, then briefly show the installer]**

“The Welcome app makes optional software easy to add, and the guided installer gets Spaced Linux onto your computer in just a few steps.”

**[1:00 — Return to a clean desktop; show the project website or release page]**

“Spaced Linux 8.26.4 is available now for 64-bit PCs. Download the ISO from spacedlinux.com or GitHub, try it live, and help us build a freer, friendlier Linux desktop.”

**[1:14 — Logo end card]**

“Spaced Linux. Familiar on the surface. Freedom all the way down.”
