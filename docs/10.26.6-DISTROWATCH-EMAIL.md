Subject: Spaced Linux 10.26.6 — desktop, installer and Windows sharing improvements since 9.26

Hello DistroWatch team,

Please consider announcing Spaced Linux 10.26.6, the latest update to our
Devuan Ceres-based desktop distribution. Spaced uses sysvinit, MATE and
Compiz, with Flatpak/Flathub for desktop applications and native packages
for system tools.

Since your announcement of Spaced Linux 9.26 in September, we have focused
on making everyday desktop tasks more consistent, improving installation
and updates, and addressing problems reported by users. The improvements
span the September maintenance releases and the October release line.
For readers coming from 10.26.1, highlights include the Qt/LibreOffice theme
fix, simpler theme names and new presets, desktop theme access, improved
terminal colors and rename contrast, audio-profile persistence, Samba
startup recovery, safer NVIDIA compatibility handling, update recovery,
and the smaller ISO. The fuller summary below covers the changes since
your September announcement.

**Desktop appearance and usability**

- The desktop offers 13 theme presets with simpler names and coordinated window borders,
  controls, panels, wallpaper, cursors and terminal colors. Theme switching
  does less repeated work; wallpaper changes no longer require a separate
  confirmation. Android and Mac OS X retain their top panel and bottom dock.
- The desktop context menu now includes Change Theme. Qt and LibreOffice
  applications receive the session settings needed to follow the desktop
  theme. GTK4 applications no longer inherit an incompatible forced GTK3
  theme from Flatpak overrides.
- Selection contrast, dark-theme file renaming, title-bar button hit areas,
  and Ubuntu and Windows 7 Dark styling have been improved. New terminal
  windows immediately receive the active preset's colors.
- The force-close cursor is a large, visible red X. Compiz's paint-fire
  defaults are finer, with a dedicated clear shortcut. Screenshot behavior,
  desktop save paths and window resize borders have received fixes.
- Display settings, desktop icon positions and chosen audio outputs are
  preserved more reliably. Audio recovery handles hardware profiles and
  reconnection more carefully. Screen blanking and screensaver defaults
  avoid interrupting users, while retaining their explicit preferences.
- Custom keyboard shortcuts can launch scripts, Flatpak app IDs or files
  through the new spaced-open-target helper. GDebi opens downloaded Debian
  packages, folders open in Caja, and script files open in the text editor.

**Windows networking and file management**

- Samba is enabled consistently after installation and upgrades, with a
  network-ready retry that fixes a Wi-Fi startup race. Shared folders inside
  home directories have the traversal permissions required for guest access.
- Windows Sharing Password provides an authenticated Samba account for
  Windows clients that require sign-in and signing. WSD discovery runs under
  sysvinit, alongside mDNS discovery, and Caja's sharing integration is included.
- Caja preserves the filename chosen in a conflict dialog when moving
  between filesystems, through a backport of merged upstream MATE PR #1888.
  Gigolo mount opening and off-screen window behavior have also been improved.

**Installation, updates and hardware support**

- Calamares installation fixes cover live-user removal, the installed user's
  UID/GID, and reboot after removing the installation medium. Wi-Fi password dialogs
  retain keyboard focus. VirtualBox default-controller and installer-launch
  checks are part of release testing.
- Spaced Update has clearer progress, release notes and recovery from
  interrupted package configuration. It refreshes the installed identity
  after upgrading, handles month/year version rollover, removes duplicate
  APT entries, and distinguishes an application-update failure from a failed
  OS upgrade. Checking for updates does not require an administrator password.
- Graphics fixes include the Xorg/AMD driver ABI correction and improved
  driver recovery. GTX 10-series Pascal cards are protected from installation
  of NVIDIA drivers newer than the compatible 580 branch.
- Desktop startup, decorator supervision, keyring integration, audio event
  handling and offline retry behavior have received reliability fixes.
  Cleanup tools confirm destructive selections and protect essential system
  packages. Core-dump storage is bounded.

**Applications, help and a smaller image**

- Welcome offers individual application installation, clearer installed-app
  actions, and local help through About Spaced Linux. Bazaar has improved
  loading, discovery, labels and scaling, with Open With integration.
- Browser defaults have fewer promotional distractions. Automatic Flatpak
  desktop shortcuts no longer clutter the desktop. Bookmarks, application
  metadata, user folders and missing desktop dependencies have been corrected.
- Wallpaper deduplication, package cleanup and improved live-filesystem
  compression reduce the installation image. The compression change alone
  saved 131 MB (8.4%) in a controlled comparison using the 10.26.5 filesystem.

These changes retain Spaced's familiar desktop and systemd-free design.
Existing users receive system fixes through the signed Spaced APT repository
and Spaced Update; Welcome and Bazaar also have their own application releases.
