# Spaced 11.26.4 - fleet branch integration (task i02, issue #426)

Integration branch `release/11.26.4`, built from `origin/main` by merging the
23 finished fleet branches from `tasks/i02-branches.txt` in list order with
`git merge --no-ff`. No ISO is built here and no PR is opened (Spaced rule:
fixes ship together in the next release). 19 branches merged; 4 skipped with
reasons below.

## Merged (user-facing)

- `strata/f003-spaced-p2p-repos-design-doc` - design document for
  torrent/P2P-based Spaced repositories (`docs/P2P-REPOS.md`); design only,
  nothing implemented.
- `strata/f034-spaced-audit-systemd-pin-pattern` - the anti-systemd APT pin and
  the Spaced Update transaction guard now cover the whole `systemd-*` family
  (audit row a08-13); the sysusers/tmpfiles providers stay installable.
- `strata/f045-spaced-wine-optin-launcher` - `spaced-wine-run`, the opt-in Wine
  launcher: one prefix per app, log per app, `--enable-mime` opt-in; Wine stays
  out of the base image.
- `strata/f052-spaced-compiz-video-help-link` - the five-minute Compiz tutorial
  video is linked from the shipped help and the website (#158).
- `strata/f057-spaced-panel-applet-backgrounds` - every shipped theme now lets
  the panel's applets (Menu, clock/date, volume, show-desktop) inherit the
  panel's own background (#387).
- `strata/f066-spaced-migration-report` - `spaced-migration-report`: snapshot
  the old desktop's apps before migrating, then report what was lost, why, and
  the exact command to get each back (#417); ships `app-set.txt` and
  `scripts/gen-app-set.sh`.
- `strata/f074-spaced-voxa-integration-boundary` - `docs/VOXA-INTEGRATION.md`:
  the supported Voxa v1 integration boundary (#238, #283); documentation only.
- `strata/f078-freecad-flatpak-gui-freeze` - the measured root cause of the
  FreeCAD 1.1.4 flatpak gray freeze (notification-area self-deadlock) recorded
  in `docs/FIXES.md` with the verified workaround command and a record test.
- `strata/f080-spaced-voxa-greeter-contract` - `docs/VOXA-GREETER-CONTRACT.md`:
  the staged M0-M5 contract required before any Voxa greeter work (#283);
  documentation only.
- `strata/f100-spaced-pdf-viewer-capability-test` - the issue #304 PDF viewer
  capability/package test and reviewed candidate table
  (`config/pdf-viewers.yaml`, `scripts/pdf-capability-matrix.py`); Atril stays
  the shipped default until it goes green.
- `strata/f101-spaced-xlibre-opt-in-test-image` - Xlibre becomes an opt-in test
  image with a refusal guard; Xorg stays the default (#314).
- `strata/f105-spaced-caja-right-click-extensions-native` - the Caja
  right-click terminal extension becomes first-party; the distro-level
  `caja-open-terminal` package is out of the image set, guarded by
  `scripts/check.sh` (#302).
- `strata/f191-spaced-systemd-unit-to-init-generator` - `scripts/spaced-init-gen`
  derives sysvinit init scripts from systemd `.service` units for software that
  no longer ships one (#431); it never enables or starts systemd.
- `strata/f201-spaced-sound-device-naming` - headless sound device-naming layer
  (`spaced_sound_names.py`) for the Sound Manager line (#429).
- `strata/f221-spaced-migration-readiness-check` - `spaced-migration-check`:
  read-only migration readiness report for derivatives (issue #417).
- `strata/f222-spaced-gpu-roles` - `spaced-gpu-roles`: desktop stays on the
  iGPU, the discrete GPU is left free (issue #426).
- `strata/f223-spaced-samba-wsdd-regression` - the network dispatcher brings up
  `spaced-wsdd` after `smbd` on interface-ready, idempotently, without leaking
  the flock (#432).
- `strata/s01-spaced-gpu-manager-design` - GPU Manager design: architecture,
  pages, every user-facing string, mockups and the 11.26.4 test plan (#426);
  design only.
- `strata/s02-spaced-sound-manager-design` - Spaced Sound Manager design:
  inventory, app design, safety story, mockups and design guards (#429);
  design only.

## Skipped

- `strata/f049-spaced-luks-boot-cryptroot` - already shipped. Issue #420
  (encrypted installs dropping to the initramfs) shipped in 11.26.3:
  main already has `cryptsetup-initramfs` in `config/packages.yaml` and the
  shipped `spacedfstabguard` crypttab verifier (`_ensure_encrypted_root`).
  The branch carries an earlier variant of the same fix; merging it stacked a
  second, conflicting verifier in the Calamares module and its own tests then
  failed against the shipped one (measured: 2 test_luks_boot failures against
  the merged module). Nothing from the branch is needed.
- `strata/f072-spaced-orca-slicer-flatpak-env` - already shipped. Issue #423
  (OrcaSlicer blank setup wizard) shipped in 11.26.3 as
  `overlays/usr/local/bin/spaced-flatpak-app-env`. The branch is an earlier
  iteration: its add/add versions would have regressed the shipped
  "record completion only on success; failures retry" semantics and dropped
  the shipped FreeCAD call from the `flatpak` wrapper.
- `strata/f083-spaced-freecad-flatpak-override` - already shipped. Issue #425
  (FreeCAD flatpak freeze workaround) shipped in 11.26.3 as the per-user
  `spaced-freecad-flatpak-env`. The branch would additionally ship a
  system-level `var/lib/flatpak/overrides` file plus a postinst step and
  check.sh assertions for it - a second mechanism for the same workaround,
  which the 11.26.3 release deliberately did not use. Its investigation docs
  are kept via f078, which merged cleanly.
- `strata/f220-spaced-caja-open-terminal` - duplicate of f105. Same issue
  (#302), second independent implementation of the same extension file with
  different label/icon strings ("Open in Terminal Here" /
  `utilities-terminal`) and different launch mechanics (`--working-directory`
  vs `cwd=`); its tests only pass against its own variant. The f105 version
  (flatpak-spawn fallback, insensitive item when no terminal exists) is kept.
  If rhY prefers the f220 label, relabel the f105 extension.

## Integration fixups made during merges

- `CHANGELOG.md`, `docs/README.md`, `docs/notes/README.md`: branches prepend
  or index-add the same sections; both sides kept verbatim. CHANGELOG.md now
  contains two `11.26.2-2` sections and three `Unreleased` sections from
  different branches - the release editor must fold them into one 11.26.4
  section at cut time (never touching shipped 11.26.3 entries).
- f052 vs earlier branches in `tests/test_spaced_update_contrast.py`: the
  auto-merge duplicated `PYTHONDONTWRITEBYTECODE` inside one `dict(...)` call
  (SyntaxError); reduced to the single canonical entry.
- f066 vs f105 in `config/packages.yaml`: f105 deletes the `file_managers`
  group that f066's `scripts/gen-app-set.sh` requires; kept the group as an
  empty list (f105's own guard only forbids the package name inside it) and
  regenerated `overlays/usr/share/spaced-linux/app-set.txt` with the repo's
  own `bash scripts/gen-app-set.sh`.
- f101 vs f034 in `tests/test_xlibre_optin_image.py`: the "ABI guard files are
  byte-unchanged vs origin/main" test is wrong by construction on an
  integration branch that deliberately contains f034's guard change. It now
  compares against the branch state immediately before the f101 merge (the
  author's real invariant: f101 itself must never touch the Xorg ABI guard);
  with no f101 merge present it still compares against origin/main. The
  refusal-guard behaviour tests are untouched.
- Stale untracked `overlays/usr/lib/spaced-linux/__pycache__` (left by an
  earlier session) removed; `scripts/check.sh` refuses bytecode in overlays/.
