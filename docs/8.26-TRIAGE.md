# Spaced Linux 8.26 issue triage

Reviewed against the GitHub tracker and the Data-drive runtime screenshots on
2026-08-10. The 8.26.3 ISO passes KVM and VirtualBox BIOS/EFI live-desktop
smoke testing; physical hardware and full installer acceptance remain.

## First-pass fixes in this tree

- [#83 — panel not loading properly on reboot](https://github.com/crhy/spaced/issues/83): the running upgraded profile was missing `volume-control-applet` even though the current layout contains it. The v3 first-login migration now restores missing canonical objects without resetting customized panel content. Reboot validation remains required.
- [#65 — small window-button hitboxes](https://github.com/crhy/spaced/issues/65): every selectable Metacity theme now has larger normal and utility titlebar geometry, while glyphs stay centered. Validate at 1x and 2x scale before closing.
- [#35 — links opening in Pluma](https://github.com/crhy/spaced/issues/35): Brave defaults now exist in both the system application database and new-user `mimeapps.list`. Fresh-user `xdg-open`, GIO, HTML-file, and reboot tests remain.
- [#46 — automated release validation](https://github.com/crhy/spaced/issues/46): the local gate now covers all shipped shell and Python sources, release-string drift, dynamic release assets, panel migration content, visual target metrics, and executable image mistakes. Built-SquashFS and CI coverage remain.
- [#38 and #88 — low-quality device/media icons](https://github.com/crhy/spaced/issues/38): all themes now resolve scalable Papirus device, ISO, and volume assets before hicolor raster fallbacks; the two native Linux themes retain their authored scalable overrides.
- [#39 — Open as Administrator](https://github.com/crhy/spaced/issues/39): `caja-admin` is now part of the desktop package set, following the maintainer's request to use the packaged extension.
- [#60 — Timeshift backups](https://github.com/crhy/spaced/issues/60): Timeshift is now included as the ext4-compatible snapshot UI; scheduling remains opt-in.
- [#90 — Calamares location](https://github.com/crhy/spaced/issues/90): the offline/default location is explicitly America/Los_Angeles rather than Calamares's New York fallback.
- [#93 — Windows shared-drive GUI](https://github.com/crhy/spaced/issues/93): Gigolo now complements the existing `gvfs-backends` support for browsing and bookmarking SMB shares.
- [#94 — persistent login](https://github.com/crhy/spaced/issues/94): the installed LightDM config no longer retains the live `user` autologin and explicitly shows its AccountsService-backed remembered-user list.
- [#92 — live medium not found](https://github.com/crhy/spaced/issues/92): KVM reproduced the exact initramfs failure. The `live-media-timeout=60` argument suppressed scanning until the built-in 60-iteration search had ended; it is removed from every boot path, the source gate rejects its return, and the rebuilt ISO reaches the full live desktop in KVM.

## Bugs requiring focused runtime or hardware testing

- [#64 — scaling after NVIDIA install](https://github.com/crhy/spaced/issues/64): 8.26 retains 1.2x default text scaling and high-density 2x detection, but the NVIDIA success/reboot path still needs monitor-aware validation.
- [#78 — missing checkboxes in Dolphin](https://github.com/crhy/spaced/issues/78): scalable checkbox/radio glyphs are present; reproduce in the current Dolphin Flatpak/runtime before changing Qt theming.
- [#61 — Bazaar install failures and light appearance](https://github.com/crhy/spaced/issues/61): suggested installs now retry each app independently instead of aborting the entire batch; test a real install through Bazaar, the system/user Flathub remotes, portal services, and dark-theme propagation.
- [#10 — applications not following themes](https://github.com/crhy/spaced/issues/10), [#36 — theme color inconsistencies](https://github.com/crhy/spaced/issues/36), and [#45 — Flatpak integration](https://github.com/crhy/spaced/issues/45): treat as one cross-toolkit visual matrix covering native GTK, LibreOffice, Qt/Dolphin, and representative Flatpaks.
- [#43 — installed-system live leftovers](https://github.com/crhy/spaced/issues/43) and [#47 — full RC installation matrix](https://github.com/crhy/spaced/issues/47): require a complete install/reboot matrix and cannot be accepted from live-desktop smoke tests alone.
- [#89 — VirtualBox installer freeze](https://github.com/crhy/spaced/issues/89): Calamares now forces its Qt Quick software backend, and the live desktop passes VirtualBox BIOS and EFI boots with VBoxSVGA; full interactive installation acceptance remains required.

## Deferred feature work

The Windows 7 Aero theme (#82), USB tools (#81), full Samba sharing wizard
(#80), bundled Ollama model (#79), Wine automation (#50), and peer-to-peer
distribution/application proposals (#9, #51–#53) are not low-risk release
polish. They remain outside this first 8.26 stabilization pass.
