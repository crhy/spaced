# Spaced Linux 8.26 issue triage

## 8.26.9 stabilization fixes

The 8.26.9 pass keeps the first-party application path release-safe without
embedding its large Flatpak runtimes in the live image:

- [#155](https://github.com/crhy/spaced/issues/155): remove the preinstalled
  SpacedBazaar Flatpak and its GNOME/Mesa/locale payload from the ISO. The
  release gate rejects any ISO at or above GitHub's 2 GiB asset limit.
- [#156](https://github.com/crhy/spaced/issues/156) supersedes
  [#137](https://github.com/crhy/spaced/issues/137): remove Plymouth from the
  package set and Calamares, use a quiet hidden-cursor default boot, and retain
  a verbose GRUB entry for diagnosis.
- [spacedwelcome#5](https://github.com/crhy/spacedwelcome/issues/5): use every
  Flathub application's actual `stable` branch instead of the nonexistent
  catalog default, while retaining the signed CRHY application branches.
- [spacedupdate#15](https://github.com/crhy/spacedupdate/issues/15): remove a
  duplicate Flatpak host bridge so the OS Release tab displays the installed
  Spaced Linux version instead of `Unknown`.

- [spacedbazaar#6](https://github.com/crhy/spacedbazaar/issues/6): publish every released CRHY desktop Flatpak through the signed `spaced-github` repository and install by application ID.
- [spacedbazaar#7](https://github.com/crhy/spacedbazaar/issues/7): retain the dedicated updating page and spinner while first-boot catalogs refresh.
- [spacedbazaar#11](https://github.com/crhy/spacedbazaar/issues/11) and [spacedwelcome#3](https://github.com/crhy/spacedwelcome/issues/3): require matching non-empty exported icons for catalog publication and correct Welcome's native icon name.
- [spacedwelcome#1](https://github.com/crhy/spacedwelcome/issues/1): show the Welcome version and a direct SpacedLinux.com link.
- [spacedwelcome#4](https://github.com/crhy/spacedwelcome/issues/4): remove direct release-bundle inspection from Welcome and route first-party installs through the shared signed repository.
- [spacedbazaar#8](https://github.com/crhy/spacedbazaar/issues/8) and [spacedwelcome#2](https://github.com/crhy/spacedwelcome/issues/2): provide an initial task-oriented app guide whose choices open exact AppStream pages in SpacedBazaar.
- [brutalchess#3](https://github.com/crhy/brutalchess/issues/3): replace the green dark-square marble with neutral charcoal-gray marble that matches the Spaced desktop palette.
- [#153](https://github.com/crhy/spaced/issues/153): install Ceres's `libfuse2t64` provider for legacy AppImage compatibility.
- [#150](https://github.com/crhy/spaced/issues/150): replace MATE's generic About entry with a branded Spaced System Info window showing release, desktop, kernel, architecture, CPU, and memory details.
- [#149](https://github.com/crhy/spaced/issues/149): arm a space-guarded, installed-system-only SysV worker after Calamares and create one Timeshift restore point named **Fresh install**. It never runs in the live session or retroactively on ordinary package upgrades.
- [#145](https://github.com/crhy/spaced/issues/145): seed new Brave Flatpak profiles with visible OpenAirShips.com, SpacedLinux.com, Devuan, SpacedBazaar, and SpacedHelp bookmark-bar links.
- [#148](https://github.com/crhy/spaced/issues/148): add the first automation phase: a monthly/manual clean ISO build, source gate, KVM-or-TCG graphical desktop smoke test, and retained ISO/checksum/screenshot evidence. Physical hardware coverage remains open.
- [#151](https://github.com/crhy/spaced/issues/151), [#146](https://github.com/crhy/spaced/issues/146), and [#144](https://github.com/crhy/spaced/issues/144): retain and gate the existing live-only GParted authorization, compact Brisk power icon, and first-boot 0%/muted audio recovery.
- [#142](https://github.com/crhy/spaced/issues/142), [#141](https://github.com/crhy/spaced/issues/141), [#139](https://github.com/crhy/spaced/issues/139), [#138](https://github.com/crhy/spaced/issues/138), and [#85](https://github.com/crhy/spaced/issues/85): ship standalone Welcome 0.1.9 with detailed per-app install progress, the signed CRHY catalog, task-oriented Help & Apps links, a concise Compiz quick start, aligned Suggested Applications content, and canonical silver application artwork.

The release set is Voice2Text AI 0.4.3, Spaced Update 0.1.6, Brutal Chess 0.2.3, Cards With Cats 0.4.1, Spaced Welcome 0.1.9, and SpacedBazaar 0.1.5. The ISO pins Welcome's released Debian artifact and the signed central descriptor by SHA-256 plus signing-key fingerprint. SpacedBazaar and the application catalog are installed after Calamares through Welcome, so no optional Flatpak runtime is part of the ISO.

Wi-Fi focus [#152](https://github.com/crhy/spaced/issues/152) remains a release-candidate runtime check: current libnma already calls `gtk_widget_grab_focus()` on WPA/SAE/WEP password widgets and nm-applet explicitly presents the secrets window, so no focus-stealing shim is justified without reproducing the failure. Intel SGX [#143](https://github.com/crhy/spaced/issues/143) has no symptom or reproduction data; the release does not disable a CPU security feature speculatively.

The remaining large proposals are roadmap work rather than 8.26.9 stabilization changes: multi-drive Calamares/Timeshift design (#147), the full hardware matrix portion of #148, Windows 7 Aero (#82), expanded Samba/Wine integration (#80/#50), and peer-to-peer or new communication products (#9/#51–#53). The initial tutorial repository in #140 is present, while phone-specific and Windows-network tutorials remain open for expansion. They add substantial storage, security, UX, or product scope and must not be represented as release defects silently fixed by an ISO rebuild.

## 8.26.7 stabilization fixes

The 8.26.7 pass addresses every report filed after the 8.26.6 source audit:

- [#128](https://github.com/crhy/spaced/issues/128): keep the live installer session awake and unlocked without changing installed-user screensaver defaults.
- [#129](https://github.com/crhy/spaced/issues/129) and [#134](https://github.com/crhy/spaced/issues/134): cap the optional NTP attempt at 12 seconds and make every time-setting path nonfatal so offline installs cannot be left incomplete.
- [#130](https://github.com/crhy/spaced/issues/130): release only stale `/tmp/calamares-root-*` mount trees and installer-activated swap before retrying, restoring the whole-disk erase choice.
- [#131](https://github.com/crhy/spaced/issues/131): authorize GParted for the active local live user through a live-only polkit rule removed from the target.
- [#132](https://github.com/crhy/spaced/issues/132): use the transparent fancy Spaced icon throughout Calamares and match the logo widget's transparent area to its sidebar.
- [#133](https://github.com/crhy/spaced/issues/133): carry the GRUB background and fancy logo beside `theme.txt` and reference both relatively, including on separate `/boot` layouts.
- [#135](https://github.com/crhy/spaced/issues/135): declare an explicit key scope on the intentionally trusted Spaced APT source so APT 3 no longer reports a missing `Signed-By` option.
- [#136](https://github.com/crhy/spaced/issues/136): publish Scum with Cats, Brutal Chess, Spaced Update, and Voice2Text through the signed `spaced-github` Flatpak catalog; standalone Welcome and SpacedBazaar install those app IDs instead of resolving mutable GitHub bundles at login.

Issue [#107](https://github.com/crhy/spaced/issues/107) is hardened again by staging the supplied black/silver round mark directly in every active icon theme, rather than depending on inherited-theme cache lookup. The existing 8.26.6 source fixes for the older open reports remain covered by `make check`.

Reviewed against the GitHub tracker on 2026-08-22. Source, package, ISO,
live-session, and installed-system runtime validation must pass before 8.26.7 is
published.

## First-pass fixes in this tree

- [#83 — panel not loading properly on reboot](https://github.com/crhy/spaced/issues/83): the running upgraded profile was missing `volume-control-applet` even though the current layout contains it. The v3 first-login migration now restores missing canonical objects without resetting customized panel content. Reboot validation remains required.
- [#65 — small window-button hitboxes](https://github.com/crhy/spaced/issues/65): every selectable Metacity theme now has larger normal and utility titlebar geometry, while glyphs stay centered; both variants of all ten themes and GTK rendering at 1x/2x passed the release gate.
- [#35 — links opening in Pluma](https://github.com/crhy/spaced/issues/35): Brave defaults now exist in both the system application database and new-user `mimeapps.list`. Fresh-user `xdg-open`, GIO, HTML-file, and reboot tests remain.
- [#46 — automated release validation](https://github.com/crhy/spaced/issues/46): the local gate now covers all shipped shell and Python sources, release-string drift, dynamic release assets, panel migration content, visual target metrics, and executable image mistakes. Built-SquashFS and CI coverage remain.
- [#38 and #88 — low-quality device/media icons](https://github.com/crhy/spaced/issues/38): all themes now resolve scalable Papirus device, ISO, and volume assets before hicolor raster fallbacks; the two native Linux themes retain their authored scalable overrides.
- [#39 — Open as Administrator](https://github.com/crhy/spaced/issues/39): `caja-admin` is now part of the desktop package set, following the maintainer's request to use the packaged extension.
- [#60 — Timeshift backups](https://github.com/crhy/spaced/issues/60): Timeshift is now included as the ext4-compatible snapshot UI; scheduling remains opt-in.
- [#90 — Calamares location](https://github.com/crhy/spaced/issues/90): the offline/default location is explicitly America/Los_Angeles rather than Calamares's New York fallback.
- [#93 — Windows shared-drive GUI](https://github.com/crhy/spaced/issues/93): Gigolo now complements the existing `gvfs-backends` support for browsing and bookmarking SMB shares.
- [#94 — persistent login](https://github.com/crhy/spaced/issues/94): the installed LightDM config no longer retains the live `user` autologin and explicitly shows its AccountsService-backed remembered-user list.
- [#92 — live medium not found](https://github.com/crhy/spaced/issues/92): KVM reproduced the exact initramfs failure. The `live-media-timeout=60` argument suppressed scanning until the built-in 60-iteration search had ended; it is removed from every boot path, the source gate rejects its return, and the rebuilt ISO reaches the full live desktop in KVM.
- [#96 — LightDM-to-MATE handoff after install](https://github.com/crhy/spaced/issues/96): accepted by a full installation, ISO-detached reboot, remembered-user LightDM login, and successful installed MATE/Compiz session. The installed filesystem contains no live account override or installer launcher.
- [#86 — Calamares cleanup](https://github.com/crhy/spaced/issues/86): the transparent `spaced-logo.png` replaces the tiled icon in every installer image slot, the sidebar and widget surfaces are neutral grays instead of blue-tinted shades, and the Qt Quick slideshow scrollbar is a light accent via `/etc/xdg/QtProject/qtquickcontrols2.conf` (guarded by `make check`).
- [#87 — ugly buttons](https://github.com/crhy/spaced/issues/87): the default buttons now use clean 1px outlines, soft radius, calm hover/active states, and a quiet accent border on suggested actions; GTK 1x/2x and installed Welcome screenshots passed.
- [#55 — Brisk menu icon](https://github.com/crhy/spaced/issues/55): the light, dark, symbolic, and hicolor launch icons now use the legible round Spaced mark rather than the thin standalone “S”.
- [#61 — Bazaar install failures](https://github.com/crhy/spaced/issues/61): SpacedBazaar 0.1 uses the independent `io.github.crhy.SpacedBazaar` identity, installs apps for the current user without a scope chooser, and is downloaded directly from the SpacedBazaar GitHub release rather than falling back to the broken upstream Flatpak.
- [#78 — missing checkboxes in Dolphin](https://github.com/crhy/spaced/issues/78): Qt keeps the GTK-derived palette but uses the Fusion widget style, matching the reporter's successful Fusion test and restoring complete native checkbox indicators.
- [#100 — GParted](https://github.com/crhy/spaced/issues/100): `gparted` is now in the default application set and the release source gate.
- [#101 — opaque desktop selection](https://github.com/crhy/spaced/issues/101): the GTK rubber-band surface now explicitly disables background images and uses a translucent selection fill without a shadow.
