# Spaced Linux 8.26 issue triage

Reviewed against the GitHub tracker and the Data-drive runtime screenshots on
2026-08-15. The 8.26.5 release passed the repository source gate, a clean ISO
build, portable SHA-256 verification, SquashFS/package inspection, and graphical
KVM and VirtualBox BIOS/EFI live boots. Every VM reached live SSH and a running
MATE/Compiz/Caja desktop, and both VirtualBox paths produced nonblank captures.
The previous 8.26.4 candidate additionally passed a complete VirtualBox BIOS
install, ISO-detached reboot, LightDM login, MATE session, and installed-filesystem
audit. Physical-hardware and a fresh 8.26.5 installation matrix remain pending.

## First-pass fixes in this tree

- [#83 — panel not loading properly on reboot](https://github.com/crhy/spaced/issues/83): the running upgraded profile was missing `volume-control-applet` even though the current layout contains it. The v3 first-login migration now restores missing canonical objects without resetting customized panel content. Reboot validation remains required.
- [#65 — small window-button hitboxes](https://github.com/crhy/spaced/issues/65): every selectable Metacity theme now has larger normal and utility titlebar geometry, while glyphs stay centered; both variants of all ten themes and GTK rendering at 1x/2x passed the release gate.
- [#35 — links opening in Pluma](https://github.com/crhy/spaced/issues/35): Brave defaults now exist in both the system application database and new-user `mimeapps.list`. Fresh-user `xdg-open`, GIO, HTML-file, and reboot tests remain.
- [#46 — automated release validation](https://github.com/crhy/spaced/issues/46): the local gate now covers all shipped shell and Python sources, release-string drift, dynamic release assets, panel migration content, visual target metrics, and executable image mistakes. Built-SquashFS and CI coverage remain.
- [#38 and #88 — low-quality device/media icons](https://github.com/crhy/spaced/issues/38): all themes now resolve scalable Papirus device, ISO, and volume assets before hicolor raster fallbacks; the two native Linux themes retain their authored scalable overrides.
- [#39 — Open as Administrator](https://github.com/crhy/spaced/issues/39): `caja-admin` is now part of the desktop package set, following the maintainer's request to use the packaged extension.
- [#60 — Timeshift backups](https://github.com/crhy/spaced/issues/60): Timeshift is now included as the ext4-compatible snapshot UI; scheduling remains opt-in.
- [#90 — Calamares location](https://github.com/crhy/spaced/issues/90): the offline/default location is explicitly America/Los_Angeles rather than Calamares's New York fallback.
- [#93 — Windows shared-drive GUI](https://github.com/crhy/spaced/issues/93): Gigolo now complements the existing `gvfs-backends` support for browsing and bookmarking SMB shares.
- [#94 — persistent login](https://github.com/crhy/spaced/issues/94): the installed LightDM config no longer retains the live `user` autologin and explicitly shows its AccountsService-backed remembered-user list.
- [#92 — live medium not found](https://github.com/crhy/spaced/issues/92): KVM reproduced the exact initramfs failure. The `live-media-timeout=60` argument suppressed scanning until the built-in 60-iteration search had ended; it is removed from every boot path, the source gate rejects its return, and the rebuilt ISO reaches the full live desktop in KVM.
- [#96 — LightDM-to-MATE handoff after install](https://github.com/crhy/spaced/issues/96): accepted by a full installation, ISO-detached reboot, remembered-user LightDM login, and successful installed MATE/Compiz session. The installed filesystem contains no live account override or installer launcher.
- [#86 — Calamares cleanup](https://github.com/crhy/spaced/issues/86): the transparent `spaced-logo.png` replaces the tiled icon in every installer image slot, the sidebar and widget surfaces are neutral grays instead of blue-tinted shades, and the Qt Quick slideshow scrollbar is a light accent via `/etc/xdg/QtProject/qtquickcontrols2.conf` (guarded by `make check`).
- [#87 — ugly buttons](https://github.com/crhy/spaced/issues/87): the default buttons now use clean 1px outlines, soft radius, calm hover/active states, and a quiet accent border on suggested actions; GTK 1x/2x and installed Welcome screenshots passed.
- [#55 — Brisk menu icon](https://github.com/crhy/spaced/issues/55): the light, dark, symbolic, and hicolor launch icons now use the legible round Spaced mark rather than the thin standalone “S”.
- [#61 — Bazaar install failures](https://github.com/crhy/spaced/issues/61): [SpacedBazaar 0.9.4-spaced1](https://github.com/crhy/spacedbazaar/releases/tag/0.9.4-spaced1) merges upstream 0.9.4, retains the writable user-installation preference, removes the account-specific home path, and passed a full sandboxed Flathub install transaction.
- [#78 — missing checkboxes in Dolphin](https://github.com/crhy/spaced/issues/78): Qt keeps the GTK-derived palette but uses the Fusion widget style, matching the reporter's successful Fusion test and restoring complete native checkbox indicators.
- [#100 — GParted](https://github.com/crhy/spaced/issues/100): `gparted` is now in the default application set and the release source gate.
- [#101 — opaque desktop selection](https://github.com/crhy/spaced/issues/101): the GTK rubber-band surface now explicitly disables background images and uses a translucent selection fill without a shadow.

## Bugs requiring focused runtime or hardware testing

- [#64 — scaling after NVIDIA install](https://github.com/crhy/spaced/issues/64): 8.26 retains 1.2x default text scaling and high-density 2x detection, but the NVIDIA success/reboot path still needs monitor-aware validation.
- [#10 — applications not following themes](https://github.com/crhy/spaced/issues/10), [#36 — theme color inconsistencies](https://github.com/crhy/spaced/issues/36), and [#45 — Flatpak integration](https://github.com/crhy/spaced/issues/45): require one cross-toolkit visual matrix covering native GTK, LibreOffice, Qt/Dolphin, and representative Flatpaks. The source already selects LibreOffice's GTK3 integration and the portal `color-scheme`, but those settings are not accepted until the runtime matrix and keyring/portal checks pass.
- [#43 — installed-system live leftovers](https://github.com/crhy/spaced/issues/43) and [#47 — full RC installation matrix](https://github.com/crhy/spaced/issues/47): one complete VirtualBox BIOS installation is accepted, including removal of Calamares, live SSH/sudo/LightDM overrides, and the live installer launcher. EFI installation and physical-hardware coverage remain.
- [#89 — VirtualBox installer freeze](https://github.com/crhy/spaced/issues/89): accepted by a complete interactive VirtualBox installation with the forced Qt Quick software path, followed by disk boot and login. Both BIOS and EFI live-desktop boots also pass with VBoxSVGA.

## Deferred feature work

The Windows 7 Aero theme (#82), USB tools (#81), full Samba sharing wizard
(#80), bundled Ollama model (#79), Wine automation (#50), and peer-to-peer
distribution/application proposals (#9, #51–#53) are not low-risk release
polish. They remain outside this first 8.26 stabilization pass.
